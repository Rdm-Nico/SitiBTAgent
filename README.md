# SitiBT-Agent-AI
Questa L'app crea un chatbot su whatsapp per aggiornare delle informazioni nel database SQL Server di Siti per quanto riguarda i tecnini e i commerciali.
## Installazione
```bash
pip install -r requirements.txt
```
## Run
```bash
python run.py -c config.yaml
```
Per comprendere in modo esaustivo come funziona l'app cliccare [qui](/docs/arch.md).

Invece per una guida rapida al funzionamento seguire il [setup](/docs/setup.md)
